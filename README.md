# 珈琲テイスティングノート

お店で飲んだ一杯と、家で淹れた一杯（自家焙煎を含む）を記録するスマホ向けWebアプリ。

## できること

- **お店の一杯**：現在地から近くのコーヒー店を探して選ぶ／メニューを撮ると品名・産地・精製・焙煎度・値段・味の説明を読み取り、飲んだものをタップで選ぶ
- **家の一杯**：豆の袋を撮って読み取る／自家焙煎・焙煎日・器具・豆と湯の量（比率は自動）・湯温・挽き目・時間
- **写真**：カップ、店の雰囲気、デザート・料理、メニュー（家は 豆・袋、淹れている様子 など）
- **テイスティング**（味わう順に7段）
  1. 香り：強さ（家は粉の香りも）と、感じた香りの分類
  2. 味：主な味（5つの基本の味から2つ）、酸味・甘さ・苦味の強さ、酸の質（アシディティ）
  3. 口あたり（マウスフィール）：重さと質感
  4. 風味（フレーバー）：大きな分類 → 細かい分類
  5. 余韻（アフターテイスト）：長さと質、冷めてからの変化
  6. 印象と好み：強さのレーダー、好み★、また飲みたい
  7. 風味の円：それまでの入力（説明文・分類・酸の質・精製・焙煎度・産地）から円のどこに当たるかを提案し、点線で表示。選んで確定する
- **表紙**：手帳・一杯・年輪の3案（設定で切り替え）
- **味の地図**：全記録を「酸味が主役 ↔ 苦味が主役」×「軽い ↔ 重い」に並べる／★4以上の一杯から好みの重心を出す／よく感じる風味・よく行くお店
- 記録は端末の中（IndexedDB）に保存。設定画面から写真ごと控えを書き出し・読み込みできる
- ホーム画面に追加でき、電波がなくても開ける

## つくり

```
public/            画面（そのまま配信される）
  index.html  style.css  sw.js  manifest.webmanifest  icons/
  js/app.js        画面と動き
  js/flavors.js    風味の言葉・専門用語・評価軸
  js/charts.js     風味の円・レーダー・味の地図（SVG）
  js/db.js         端末内の保存
src/worker.js      /api/nearby（近くの店） /api/read（写真の読み取り）
wrangler.jsonc     Cloudflare の設定
```

- 近くの店：OpenStreetMap（Overpass API）。キー不要・無料。店が登録されていない場合は手入力
- 写真の読み取り：Cloudflare の AI（Gemma 4。キー不要、1日の無料枠あり）。読めないときは、写真の文字を貼り付けて端末の中だけで読み取る予備あり。Claude のキーを登録すると Claude に切り替わる
- BGM：オリジナルのカフェ風ピアノ曲（tools/compose_bgm.py で作曲・書き出し。ピアノ音色 FluidR3 GM, CC BY 3.0）。既定はオン、一覧・地図・設定で切り替え

## 公開の手順（GitHub → Cloudflare）

1. GitHub に新しいリポジトリ `coffee`を作り、このフォルダの中身をそのまま上げる
2. Cloudflare の「Workers & Pages」→「作成」→「GitHub からインポート」でこのリポジトリを選ぶ
   - ルートディレクトリ：`/`（リポジトリ直下に置いた場合）
   - デプロイコマンド：`npx wrangler deploy`
3. （任意）Worker の「設定 → 変数とシークレット」に登録すると機能が変わる
   - `ANTHROPIC_API_KEY`：読み取りを Claude に切り替えて精度を上げる
   - `APP_TOKEN`：好きな合言葉。他人に読み取り機能を使われないための鍵（登録したら設定画面にも同じものを入れる）
4. 公開されたアドレスをスマホで開く
5. 共有メニューから「ホーム画面に追加」

読み取りのモデルは `wrangler.jsonc` の `MODEL` で変えられる（既定 `claude-sonnet-5-5`）。

## 手元で試す

```
npm install
npx wrangler dev
```

秘密の値は `.dev.vars` に `ANTHROPIC_API_KEY=...` と `APP_TOKEN=...` を書く（このファイルはGitHubに上げない）。

## テイスティングの設計の土台

- SCAの新しい評価方式（Coffee Value Assessment, 2024年11月に規格化）：「どれだけ感じたか（強さ）」と「好きか（好み）」を分ける／当てはまるものを全部選ぶ（CATA）／まず大きな分類、そのあと細かく
- 主な味を2つ選ぶ欄、口あたりの言葉（なめらか・ざらつき・オイリー・金属っぽい・口が渇く）も同方式から
- カップ・オブ・エクセレンス：酸や口あたりは量より質を見る
- 冷めていく途中の変化を見るのはカッピングの基本手順から
