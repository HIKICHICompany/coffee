# 一杯の記録帳

お店で飲んだ一杯と、家で淹れた一杯（自家焙煎を含む）を記録するスマホ向けWebアプリ。

## できること

- **お店の一杯**：現在地から近くのコーヒー店を探して選ぶ／メニューを撮ると品名・産地・精製・焙煎度・値段・味の説明を読み取り、飲んだものをタップで選ぶ
- **家の一杯**：豆の袋を撮って読み取る／自家焙煎・焙煎日・器具・豆と湯の量（比率は自動）・湯温・挽き目・時間
- **写真**：カップ、店の雰囲気、デザート・料理、メニュー（家は 豆・袋、淹れている様子 など）
- **テイスティング**
  - 風味の円（9分類・3層の独自の円）。言葉をタップすると円の位置が光り、「味の重心」が円の上に印で出る
  - 酸の質（アシディティ）、口あたり（マウスフィール）、余韻（アフターテイスト）、全体の印象をタップで選ぶ
  - 7つの軸（酸味・甘さ・苦味・コク・余韻・透明感・バランス）を1〜5で付け、レーダーで表示
- **味の地図**：全記録を「酸味が主役 ↔ 苦味が主役」×「軽い ↔ 重い」に並べる／★4以上の一杯から好みの重心を出す／よく感じる風味・よく行くお店
- 記録は端末の中（IndexedDB）に保存。設定画面から写真ごと控えを書き出し・読み込みできる
- ホーム画面に追加でき、電波がなくても開ける

## つくり

```
public/            画面（そのまま配信される）
  index.html  style.css  sw.js  manifest.webmanifest  icons/
  js/app.js        画面と動き
  js/flavors.js    風味の言葉・専門用語・評価軸
  js/charts.js     風味の円・レーダー・味の地図（SVG）
  js/db.js         端末内の保存
src/worker.js      /api/nearby（近くの店） /api/read（写真の読み取り）
wrangler.jsonc     Cloudflare の設定
```

- 近くの店：OpenStreetMap（Overpass API）。キー不要・無料。店が登録されていない場合は手入力
- 写真の読み取り：Claude API（画像を読ませてJSONで返させる）

## 公開の手順（GitHub → Cloudflare）

1. GitHub に新しいリポジトリ `coffee`を作り、このフォルダの中身をそのまま上げる
2. Cloudflare の「Workers & Pages」→「作成」→「GitHub からインポート」でこのリポジトリを選ぶ
   - ルートディレクトリ：`/`（リポジトリ直下に置いた場合）
   - デプロイコマンド：`npx wrangler deploy`
3. できた Worker の「設定 → 変数とシークレット」に2つ登録する（種類はシークレット）
   - `ANTHROPIC_API_KEY`：Claude API のキー（console.anthropic.com で発行）
   - `APP_TOKEN`：好きな合言葉。他人に読み取り機能を使われないための鍵
4. 公開されたアドレスをスマホで開き、設定画面で同じ合言葉を入れる
5. 共有メニューから「ホーム画面に追加」

読み取りのモデルは `wrangler.jsonc` の `MODEL` で変えられる（既定 `claude-sonnet-5-5`）。

## 手元で試す

```
npm install
npx wrangler dev
```

秘密の値は `.dev.vars` に `ANTHROPIC_API_KEY=...` と `APP_TOKEN=...` を書く（このファイルはGitHubに上げない）。
